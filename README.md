## 🎮 Sobre o Projeto

**Martial Spirit** é um RPG educativo que une:

- Filosofia do Karatê-Do
- Autoconhecimento
- Disciplina e evolução pessoal
- Narrativa imersiva
- Estética low-poly com identidade japonesa

O jogo foi desenvolvido ao longo de **1 ano letivo**, integrando pesquisa acadêmica, design de jogos e desenvolvimento técnico no motor gráfico Unity na linguagem de programação C Sharp(C#).

---

## 🌐 Sobre o Site

Este site foi criado com dois objetivos principais:

1️⃣ Apresentar o jogo como um **produto real de portfólio**  
2️⃣ Servir como vitrine oficial para apresentação no evento **X SE²PIN**

O site organiza:

- 📖 Conceito e propósito do projeto
- 🎮 Experiência do jogo
- 🛠 Parte técnica (código e sistemas implementados)
- 🎨 Modelos 3D e assets desenvolvidos
- 📅 Processo de desenvolvimento em 1 ano letivo

Mesmo sem disponibilizar o download do jogo, o site apresenta o projeto como um produto estruturado, com identidade e maturidade técnica.
